# Weather_CLI_Fetcher
A CLI tool in Python to fetch real-time weather using the wttr.in API.

---

## Requirements

* Python 3.x
* `requests`

```bash
pip install requests
python weather.py London
```
 Output:
🌤️  Weather in London:
   - Temperature: 18°C
   - Condition:   Partly cloudy
   - Humidity:    65%
